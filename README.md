This repository features a curated collection of visually impressive presentations and brainstorming samples. 

**Workflow:**
* **Initial Generation:** Created using Gemini Notebook.
* **Refinement:** Manually processed and polished before uploading.

**Contents:**
* `.pptx` files provided as read-only slide decks (and most try complete with speaker notes, at least those before oct 26).
* Corresponding `.png` thumbnail images sharing the same filename.
* Presentations are optimized and compressed using [SlideSpeak](https://slidespeak.co/free-tools/compress-powerpoint-tool) (as well as their offical command line version) prior to upload.
